# Product Requirements Document (PRD)

## DO IT SERVICES — Cash Collection & Retailer Operations Platform

Based on project understanding shared by the user 

---

# 1. Project Overview

## Product Name

**DO IT SERVICES Operations Platform**

## Product Type

Web-based Progressive Web App (PWA)

## Purpose

Build a centralized operational platform for managing:

* Cash collection
* Retailer ledger management
* Staff activity
* Denomination tracking
* Reporting
* Bank deposit workflows
* Collection reconciliation

The platform will replace fragmented workflows currently spread across:

* PDF generation
* Khatabook
* Calculator apps
* Manual reporting
* Manual reconciliation systems 

---

# 2. Business Problem

## Current Problems

The existing workflow has multiple operational inefficiencies:

| Problem                            | Impact                         |
| ---------------------------------- | ------------------------------ |
| Manual collection tracking         | Human errors                   |
| Separate denomination calculations | Time wastage                   |
| Manual PDF/report creation         | Duplicate work                 |
| Khatabook dependency               | No centralized system          |
| No live visibility                 | Owner lacks real-time insights |
| Manual reconciliation              | Delays & mismatches            |
| No unified staff monitoring        | Weak accountability            |

---

# 3. Product Goals

## Primary Goals

The platform should:

* Centralize all cash collection operations
* Reduce manual data entry
* Provide real-time operational visibility
* Automate report generation
* Simplify reconciliation
* Improve staff accountability
* Maintain retailer transaction history
* Work reliably on mobile devices
* Support offline-first workflows

# 6. Functional Requirements

# Module 1 — Authentication & Authorization

## Features

### Login System

* Email/Phone login
* Password authentication
* JWT-based session handling
* Secure logout

### Role-Based Access Control

## Staff Permissions

Can:

* Login
* Create collection entries
* View own summaries
* View assigned retailers

Cannot:

* Access admin dashboards
* Edit other staff data
* Access analytics

## Admin Permissions

Can:

* View all collections
* Manage retailers
* Manage staff
* Edit entries
* Export reports
* Access analytics
* Verify collections
